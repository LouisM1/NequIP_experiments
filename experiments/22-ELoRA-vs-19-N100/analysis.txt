Experiment 22 vs experiment 19: matched N=100 validation comparison
Evaluated 28 October 2026

ELoRA: 22-ELoRA-N100-R4-9201369
Baseline: 19-LastLayerTransfer-N100-9189909
Baseline trains the final interaction layer, shared head, scales and offsets.
ELoRA trains rank-4 adapters in all four interaction layers plus the same head,
scales and offsets; the original backbone parameters stay frozen.

Comparison protocol
Both configurations have identical data, loss and fitting sections, seed 42,
and the same original E/F source checkpoint. Both fit the same 100-structure
training subset. Evaluate their minimum-validation-loss checkpoints on the
same 50 validation structures (2,400 Si sites and 4,800 O sites).
The exported model.pt state matches best.ckpt exactly for both runs.
No fitting, label calibration or test-set evaluation was performed here.
Targets are absolute DFT isotropic shieldings in ppm, not referenced shifts.

Interpretation
ELoRA improves both elements and has lower balanced MSE on 49/50 structures.
Median per-structure balanced MSE falls from 0.010106 to 0.004913.
The parity panels use identical limits for each element and show all sites.
Both models retain conspicuous low-shielding oxygen outliers. Improvements are
widespread, although difficult structures still contribute heavily to MSE.
This supports ELoRA for this matched N=100 experiment. It does not establish
seed-to-seed robustness or held-out test generalization: the validation set was
also used for scheduling, early stopping and checkpoint selection.
Fewer trainable parameters should not be read as a runtime speedup. Reported
run times were 22.9 min for ELoRA and 14.6 min for the baseline, without a
controlled same-hardware timing comparison.
